## Tìm việc từ Google

Tính năng tìm việc dùng Google Custom Search JSON API và chỉ hiển thị kết quả có URL nguồn. Đặt hai biến môi trường cho API server:

```env
GOOGLE_SEARCH_API_KEY=your_google_api_key
GOOGLE_SEARCH_ENGINE_ID=your_search_engine_id
```

Sau đó khởi động lại bằng `npm run dev`.
